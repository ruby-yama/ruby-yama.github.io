UKIYO STRINGS の遊び方と攻略のコツ

狐面の少女と、三味線の3本の弦を弾く和とサイバーのリズムゲーム。上達のコツと、壁紙の集め方をまとめました。

3本の弦を弾く

画面には三味線の3本の弦があり、撥（ばち）の形のノーツが流れてきます。ノーツが判定の線に重なった瞬間に、その弦をタップします。長いノーツは、終わりまで押し続けます。

合わない時は「ずれ」を直す

端末やイヤホンによって、音と画面がわずかにずれることがあります。設定の「ずれを自動で合わせる」で、メトロノームに合わせて8回タップすると調整されます。

難しさと奏者

  • EASY・NORMAL・HARD から選べます。まずは EASY で曲の流れを覚えましょう。
  • 奏者は4人いて、それぞれ特技があります。
  • FEVER 中は点数が上がります。

壁紙を集める

  • NORMAL 以上で正確さ90%をこえると、その曲の壁紙が手に入ります（担当の奏者で遊ぶと88%）。
  • 一部の曲は HARD だけで手に入ります。
  • 集めた壁紙はギャラリーで見られ、端末に保存したり、プレイ中の背景にしたりできます。

期間限定の曲

期間限定のイベント曲が追加されることがあります。期間中に条件をみたすと、期間が終わってもずっと遊べるようになります。
